# Backrooms — 序章可玩首版

当前入口为 Milestone 2 序章：2026 年的普通城市公寓、公司登记、整理通勤包、公共走廊与通勤街道、意外切入后室。建筑保留 2000—2010 年代生活痕迹，手机使用现代应用界面。有限 Level 0 抵达空间用于序章收束；尚无无限生成和 Levels 1–11。原 Milestone 1 两个灰盒房间及回归入口保留。

## 运行

已验证环境：Godot **4.7.2**、Windows、Jolt、Forward+ / D3D12。

在 Godot 中导入 `project.godot`，按 **F5**。主场景是 `core/prologue/main.tscn`。点击“新的一天”后选择难度，或继续已保存进度；主菜单和暂停页均可进入设置。旧基础测试入口可单独运行 `core/main.tscn`。

本机命令：

```powershell
& 'C:/Users/ZANRe/Desktop/Godot_v4.7/Godot_v4.7.2-stable_win64_console.exe' --path 'D:/ZAN/Backrooms'
```

## 操作

| 输入 | 功能 |
|---|---|
| WASD / 鼠标 | 移动 / 观察 |
| Shift / Ctrl / 空格 | 冲刺 / 按住蹲伏 / 低跳 |
| E | 中心视线交互：关闭床头闹钟、拾取物品、开门、买水 |
| Tab | 背包；点击只选中，再点取消；长按 0.32 秒拖动，拖动时 R 旋转 |
| 装备槽按钮 | 点击选择真实装备；长按拖回背包，或使用／丢弃 |
| P / Q / 右键 | 打开携带的手机 / 使用副手 / 使用主手 |
| 相机 App 的“拍摄”按钮 | 打开全屏取景，此时尚未保存照片 |
| 取景中 WASD / 鼠标 / 左键 | 移动 / 观察 / 拍照，Esc 或 P 返回手机 |
| Esc | 暂停或关闭当前界面 |
| F1 | 调试面板（先在设置→游戏开启开发者模式） |

序章从住宅开始。走到床头关闭闹钟，在实体手机的公司工作台登记姓名、生日；通过“编辑形象”打开实际人物模型的捏脸页面，调整体型、肤色、发型、发色、12 项面部与 5 项体型参数。拖动旋转，滚轮缩放；确认回填登记草稿，取消不修改角色，完成登记才提交并存档。拿起通勤包、钥匙与钱包；包内笔记本占据真实的 4×3 空间与 2.7kg 重量。整理后从玄关出门，再穿过公共走廊。手机各应用使用本地虚构内容；聊天支持自由文本，全屏相机与相册保存实际世界画面。

通勤路上可选择买一瓶水；走向街道尽头右侧的普通转角，会发生切入。携带物品、旋转布局、液体、电量和聊天状态随角色保留。背包取消帆布背景，左侧默认竖排十个装备槽，选中物品时切换为物品详情；保留实物图像、拖放、旋转、嵌套、装备和丢弃，满包时需要自行整理。住宅窗户和街道不可通行边界已有碰撞保护。

门把手和门扇会实际转动，出楼时角色迈过门槛后过渡到街道；通勤 NPC 按不同节奏行走、停顿与转身。背包图标裁去透明留白后等比容纳在占格内，旋转与拖拽使用相同比例。人物手臂与交互使用共享骨架，手机握持使用真实蒙皮手。

## 保存与范围

普通运行存档为 `user://foundation.save`，另有 `.bak` 备份。休闲可手动保存；硬核和极限只接受自动 checkpoint。序章完成登记和抵达后室时自动保存，登记前不保存。schema 3 保存独立 CharacterAppearance，迁移 schema 1/2：原 schema 1 仍恢复到灰盒路线；错误使用 2010 年的 schema 2 序章档改为 2026 年，并同步生日年份保留角色年龄。极限死亡结算后的清理限定当前 run_id。

照片另存于 `user://photos/<run_id>/`；存档只保存引用，缺少照片不破坏其余进度。成功保存后的照片清理保留当前与有效备份所属运行，无法确认归属时不扩大删除范围。

场景采用 Poly Haven CC0 家具/PBR；图标使用 Lucide ISC/MIT 子集和五个原创装备符号。人物采用项目独立适配器、66 骨骼与原生 BlendShape，玩家和两个普通通勤 NPC 共用框架。MakeHuman 官方 CC0 皮肤、眼睛、头发与鞋子已接入；基础 GD-Human 网格仍标记为评估候选，其逐文件来源证据待完善。来源见 `THIRD_PARTY_ASSETS.md`。当前仍是可玩首版：动作采用程序骨骼驱动，完整动画重定向、任意道具抓握、换装适配、环境录音、烘焙间接光和长期人工试玩尚待打磨。

## 界面与设置

状态条始终保留真实比例；沉浸状态栏仅隐藏数字。顶部常驻操作提示，右侧待办清单标注可选事项，完成后划除并渐隐。装备栏显示十个部位及实际物品缩略图；每次打开都清空选中。

设置提供游戏／画面／音频／操作四类，画面细分基础／光影／性能／氛围。默认 60 FPS 上限、垂直同步、2× MSAA，VCR 滤镜关闭。窗口分辨率调整窗口尺寸；全屏使用显示器尺寸，渲染比例控制内部 3D 清晰度。音效与环境音分总线调节，鼠标灵敏度、反转纵轴和 FOV 可独立调整。

偏好保存在 `user://preferences.cfg`，兼容旧存档的两项设置；自动验证使用独立偏好路径，不写入玩家设置文件。

## 验证

```powershell
./tools/verify_m2.ps1 -GodotPath 'C:/Users/ZANRe/Desktop/Godot_v4.7/Godot_v4.7.2-stable_win64_console.exe' -Graphical
./tools/verify_m1.ps1 -GodotPath 'C:/Users/ZANRe/Desktop/Godot_v4.7/Godot_v4.7.2-stable_win64_console.exe' -Graphical -UserStorage
```

- 默认测试写入 `artifacts/`，不覆盖正式存档。
- M2 日志在 `artifacts/verification_m2/`，代表画面在 `artifacts/prologue_runtime/`。图形综合测试使用真实 1920×1080 渲染与自然帧时间；短时帧采样不等同于持续 60 帧认证。
- `-UserStorage` 额外使用独立的 `user://m1_validation_<pid>/` 子目录验证实际用户存储路径。
- 日志在 `artifacts/verification/`，图形截图在 `artifacts/runtime_test/`。
- `-Graphical` 还运行最小窗口背包拖放和五种窗口尺寸的 UI 验证（960×540、1280×720、1024×768、1600×900、1600×675），对应截图在 `artifacts/ui_layout/`。
- M1 功能测试采用固定步长；M2 的 1080p 综合和人物/手机图形检查使用自然帧时间。最小窗口检查等待实际 resize 事件后再检查布局。
- 无头后端不支持鼠标捕获；这一项由图形测试实际验证。
- 脚本遇到任何非零退出码或错误日志都会失败。在受限制的沙箱中，Godot 读取系统证书/写编辑器设置可能被拦截；正常桌面权限下的验证日志才是最终证据。
